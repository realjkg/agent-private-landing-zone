# End-to-end LZ journey evidence runner

This **offline** runner collects references to evidence generated by the existing Sovereign ALZ model, discovery, governance, inventory, Terraform/CDK preview and ACT-snapshot workflows. It produces a JSON review report and static HTML visualization. It does not invoke those workflows, AWS, models, Terraform, CDK, or any deployment API. It never authorizes ACT.

## Operator journey
1. From the existing local ALZ UI, instruct the private Qwen/Mistral stack to discover and assess the dedicated AWS DEV environment through authorized skills.
2. Save redacted, source-bound evidence of the actual model invocations and validator decisions; AWS identity, inventory and visual graph; OPA/IAM/SCP/RCP decisions; engine-specific native Terraform plan or CDK Change Set preview; and the **disabled** ACT snapshot. Collect independent provider observations separately.
3. For each of these eight keys, save an evidence file and its SHA-256: `instruction`, `private_models`, `discovery`, `inventory`, `governance`, `iac_preview`, `act_snapshot`, `independent_verification`.
4. Create a manifest alongside the redacted files:

```json
{
 "source_sha":"REPLACE_WITH_EXACT_40_CHAR_COMMIT",
 "engine":"TERRAFORM",
 "mode":"PREVIEW_OPERATE",
 "act_enabled":false,
 "stages":{
  "instruction":{"path":"instruction.json","sha256":"REPLACE_WITH_SHA256","source_sha":"SAME_COMMIT","engine":"SHARED","authentic":true,"verified_by":"operator"}
 }
}
```

Fill all eight entries. For CDK set engine to `CDK` and attach independent CDK provenance. Files may use `SHARED` only when evidence truly applies to both engines.

Run `python3 scripts/lz-journey-evidence.py --manifest .runs/lz-journey/manifest.json --output .runs/lz-journey/report.json --html .runs/lz-journey/report.html`.

The runner checks hashes, paths, source/engine binding, and operator attestation, **not** evidence semantics or authenticity. Even with all files present, it reports independent review required, production authorization NOT_GRANTED and release HOLD. Never upload JWTs, secrets, Terraform state or unredacted inventory.

Milestone 1 remains Preview/Operate with ACT disabled. The separately authorized Terraform-only ACT-DEV-1 pilot is governed by issue #199 and `docs/act-dev-1.md`; CDK has no equivalent DEV-only exception. Actual model execution, live AWS provider qualification, production security gates and human approvals cannot be inferred from this report.
